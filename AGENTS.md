## What this is

**Main Menu** is a personal, controller-first, landscape-primary iPhone game launcher (target device: iPhone 15 Pro). It is a console-style home screen: a horizontal row of game tiles with poster art, a Library to add games, and Settings. It works with a Bluetooth controller and also by touch. It is built into an **unsigned IPA** by GitHub Actions and sideloaded with Feather.

Features: console-style Home (tap launches, long-press menu: Launch/Edit/Remove), Library with Catalog and My games tabs, App Store search through the iTunes Search API, SteamGridDB poster art with a per-game art picker, external display support with phone dimming, a shared Shortcut launcher for games with no URL scheme, and a URL scheme finder.

## Stack

- SwiftUI, iOS 17 minimum. Project generated by **XcodeGen** from `project.yml` (the `.xcodeproj` and `Info.plist` are gitignored and generated).
- Bundle ID `dev.elder.mainmenu`. Landscape only, dark, full screen, status bar hidden.
- No third-party Swift packages.

## How launching works (important constraints)

iOS does not let a sideloaded app open another app by bundle ID (that needs private entitlements). So:

1. **URL scheme** via `UIApplication.open`. Genshin uses `genshin://`. Team Fight Tactics was confirmed working with `teamfighttactics://` through the scheme finder.
2. **Shared Shortcut fallback**: one Shortcut named exactly `Main Menu Launch`, whose action is Open App with the app set to the **Shortcut Input** variable (not "Ask Each Time"). The app opens `shortcuts://run-shortcut?name=Main%20Menu%20Launch&input=text&text=<app name>`. The per-game "App name for the Shortcut" must match the name under the icon on the Home Screen. A ready-made copy is installed from an iCloud link in `AppModel.installShortcut()` (it may be an old snapshot; if it breaks, rebuild the Shortcut by hand following the in-app guide).
3. **Scheme finder** (`Launcher.probe`): `canOpenURL` over a fixed candidate list. Candidates must also be listed under `LSApplicationQueriesSchemes` in `project.yml` (max 50 are honored). Keep the Swift list and the plist list in sync.
4. **Hollow Knight and Balatro** were sideloaded and expose no URL scheme. The fix under discussion: patch each IPA's `Payload/<App>.app/Info.plist` to add `CFBundleURLTypes` with schemes `hollowknight` and `balatro` (both already in the candidate list), re-sign in Feather, then use the finder. The user could not open the `.app` on iPhone and the IPA was too large for chat upload, so this needs a computer. Status: **open**.

## Build and release

Workflow: `.github/workflows/build.yml` on `macos-15`.
- Triggers: push to `main`, tags `v*`, and `workflow_dispatch` with a `release_version` input.
- It generates the project with XcodeGen, archives unsigned with `MARKETING_VERSION` / `CURRENT_PROJECT_VERSION` overrides, zips to `MainMenu.ipa`, uploads an artifact, and keeps a rolling prerelease named `latest` (`gh release upload --clobber`).
- A versioned release is made when `release_version` is given (or a tag is pushed), titled "Main Menu <ver>", with `RELEASE_NOTES.md` as the notes.
- Base `MARKETING_VERSION` lives in `project.yml`. Info.plist uses `$(MARKETING_VERSION)` and `$(CURRENT_PROJECT_VERSION)`.
- In the original session, creating tags or refs directly was blocked by the environment proxy, so releases were cut by dispatching the workflow:
  `gh api repos/Elderflowa/main-menu/actions/workflows/build.yml/dispatches -f ref=main -f 'inputs[release_version]=X.Y.Z'`
- Before each release: update the top heading and "What's new" section in `RELEASE_NOTES.md`.

## Companion repo: birds-eye

`Elderflowa/birds-eye` scans all public repos of the owner for releases containing an `.ipa` and generates `source.json` (AltStore/Feather source format), refreshed every 30 minutes by cron, by `repository_dispatch`, or manually:
`gh api repos/Elderflowa/birds-eye/actions/workflows/update.yml/dispatches -f ref=main`
Source URL for Feather: `https://raw.githubusercontent.com/Elderflowa/birds-eye/main/source.json`. It ignores the rolling `latest` prerelease when a versioned release exists. Feather needs every JSON field present, so the script always emits fallbacks.
